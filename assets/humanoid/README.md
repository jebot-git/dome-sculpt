# CC0 VRoid humanoid bases

Only the verified historical CC0 VRoid beta female and male source models in [vroid](vroid/README.md) are bundled for humanoid creation. Their immutable original model bytes, images, materials, rig and expression identities are retained in saved native projects. Modern restricted VRoid presets and proprietary application code are not included.

MakeHuman default meshes, converted embedded geometry and the offline mesh converter have been removed. Historical grants/hash evidence is kept separately in docs/references/makehuman. Existing MakeHuman-authored projects retain their saved geometry and metadata and remain editable/exportable; the removed creation recipe cannot regenerate a bundled model.

WORKFLOW-REFERENCES.json records the workflow references. Native shape and grooming code remains original project implementation; no Python/proprietary runtime is required.
