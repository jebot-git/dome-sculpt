# Official older-beta CC0 VRoid base models

These are the actual Base_Female and Base_Male models exported by
VRoidStudio-0.14.0, authored by pixiv Inc. / VRoid Project. They are the primary
anime/toon creator source assets. They are distinct from the current proprietary
VRoidPreset_A–Z models and from AvatarSample_A/B/C.

The author's [official older-beta model license page](https://vroid.pixiv.help/hc/en-us/articles/4402614652569-Do-VRoid-Studio-s-sample-models-come-with-conditions-of-use)
separates particular-license models from the CC0 base/sample models. The author's
[official New model grant](https://vroid.pixiv.help/hc/en-us/articles/900000088126-New-model)
expressly identifies the base as CC0 and waives pixiv's copyright and related
rights to the extent possible under law. The files independently contain exact
Base_Female/Base_Male titles, VRoid Project authorship, VRoidStudio-0.14.0
exporter identity and `licenseName: CC0`, plus permissive editing and
redistribution fields. Original embedded metadata is retained unchanged.

The archives are obtained from the [older-beta preservation mirror](https://opengameart.org/node/170868),
which documents the 0.14.0 export and explicitly excludes the non-CC0 A–C models.
The author grants and actual embedded model metadata establish license identity;
the mirror's category tag alone is not used as a grant. Full archive and model
SHA256 hashes, exact download URLs, byte sizes, original embedded permissions and
source context are recorded in `SOURCES.json`. Each file is retained byte for
byte, including original geometry, rig, UVs, morphs, images and material/MToon
metadata. The CC0 legal text is retained one directory above as `CC0-1.0.txt`.

Credit is not required by CC0; source provenance is nevertheless retained as
pixiv Inc. / VRoid Project. No VRoid application runtime or source is required.
