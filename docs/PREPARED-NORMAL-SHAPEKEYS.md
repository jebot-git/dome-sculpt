# Prepared-normal shapekey authoring

This private core milestone connects the existing native/controller authoring path to normally prepared targets. It extends exact public base `8d46dfbd610e6534a2d3ffd6413de2ce7cc8ea21`; it does not replace the accepted selection interface or add a frontend, public layout, sampler admission or archive version.

The adapter validates the current recipe and exact REST/source/sampling authority, then reconstructs a detached normal-unprepared input. Its attribute authority is the authenticated **current native prepared model**, including generated-tangent provenance. This preserves Duplicate and CaptureMix's exact current direction channels instead of silently generating a different tangent endpoint from an older N-only source.

The existing authoring kernel edits that detached input. Full normal preparation then reproduces intrinsic pixels and their initial sampled quality fields. Unchanged base N/T/W, transport policy, source/origin identities and existing stable target slots are checked before the old immutable intrinsic owners are reused. The new receipt must deep-replay successfully against the genuinely edited input. Current paint, detail, layers, masks, material values, skin and pose remain intact. Original raw N-only data and the old recipe remain in the actual source capsule; derived tangents are not relabeled as imported artist tangents.

Exact ordered-corner remapping is used in both directions. Missing, contradictory or unreferenced origin authority is refused rather than guessed. Current morph deltas are copied directly during reconstruction. Historical source rig data is retained; live rig/skin/pose stays on the current object. The first prepared source for the same intrinsic/base lineage is retained without adding a persistent source capsule per stroke. Earlier unprepared source history remains linked.

Create, Replace, Duplicate, Mirror, CaptureMix and Rename use the adapter. Existing no-op and resource/name admission stays ahead of expensive work. Restore uses the real source capsule. The Document's existing leased worker publication, cancellation and history machinery remains responsible for acceptance; accepted export cancellation/commit callbacks are unchanged.

## Core qualification

A fresh coherent optimized CPU core/support build passes five selected suites: new prepared-normal authoring43, existing shapekey authoring23, native/controller tools46, ordered strokes29 and normal preparation36. The new43 include real Document operations, queued cancellation, stale document replacement, no-op history, one Undo/Redo, controller navigation/Duplicate, actual Save/new-Document reopen and background GLB output. They verify current edited skin/nonuniform pose, exact paint/detail/masks/material values, stable target IDs, first prepared source/raw history, repeat bake after explicit rest reset, Clear and exact Restore. Genuine N-only CaptureMix preserves the current linear N/T blend and original N-only provenance.

Repeat baking while posed still refuses, leaving the scene exact. The positive repeat-bake case explicitly resets pose and morph weights first. No existing bake, UV1, prepared-source, topology/color or normal-conversion guard was relaxed.

This checkpoint is **not** final integration or completion. New independent named-policy PBR/MToon pixels, broader artist/actual-asset coverage, allocation-failure and fresh sanitizer checks, actual FLTK/compact and synthetic OpenXR workflows are the next qualification stage. The previous `f758970` and `0c6de7e` proofs remain frozen and do not substitute for current adapter evidence. Full normal-source/UV transfer, arbitrary affine preparation, current polygon-color adapters and COLOR/TEXCOORD morph support remain required.
