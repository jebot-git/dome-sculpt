## Implemented current route

A current-corner target actually prepared and baked by the native worker can now
change supported UV layouts while retaining its immutable initial descriptor,
projection, quality receipt and original before-state. A separately owning
`SourceColorUvReprojection` records exact ordered REST/corner/UV correspondence,
current topology and the same independent straight-linear RGBA field, strict
before paint/material/deformation, actual new projection, and its newly measured
quality/resource receipt. No Identity or borrowed creator accessor substitutes
for corner authority. Initial and current domains are distinct.

`reproject_source_corner_colors` is detached, bounded and cancellable. SourceUV
transfers editable common and independent PBR layers, masks and all coverages,
baked colour/PBR/ORM/emission/normal planes, and pose/skin/morph identities before
adopting the actual current projection. Native `process_uv_transfer` uses the
same own source and target polygon witnesses, captures complete before-state in
its direct PolygonOrigin, checks exact source owners at admission/publication,
and keeps the shared bridge's presealed accepted endpoint and postcommit
completion ordering. Pending Save/Close never falls back to a stale Scene.

The conditional codec is Scene23 / material8 / colour-entry3. Old Scene20 /
material6 output remains in use when no UV node is reachable. Entry3 retains all
initial entry2 keys and adds the current UV node; its immediate predecessor must
be an earlier own prepared binding. Decode proves serialized initial inheritance
and restores identical initial owners. Shared corner basis/field aliases,
before-material reachability, depth/cycles, aggregate geometry/deformation/paint/
layout budgets, feature-version scans and current descriptor consumers are
included. Unbound PA, forged REST, owner/quality/layout substitutions, orphans
and older versions remain refused. This standalone branch does not admit the
reserved Scene21/material7 normal sampling schema or Scene22 key schema.

## Normal and quality scope

Unposed source-aware UV scaling uses the existing normal conversion. Deformed
canonical normal transfer is admitted only for an exact conservative translation
certificate: all ordered triangles retain their floating-point UV differences,
and the global UV-equality partition is bijective. This keeps dynamic Mikk welds
and derivatives without substituting static authored axes. Independent actual
Mikk generation is bit-exact through37 mixed skin/morph/anisotropic poses in both
RGBA seam fixtures. Deformed fractional scale, rotation, unwrap, introduced or
merged seams, prepared intrinsic normals and unsupported role transfers retain
explicit guards. These remain required work, not completed functionality.

The default64 .7-scale controller trial correctly refused its unchanged .04
projection-error policy; its failure log is retained. The positive .7-scale
controller fixture explicitly imports256 pixels and is unposed. Lit skin/morph
consumer cases use only certified integer1/256 chart translation. Neither test
establishes universal scale/unwrap fidelity. Splitting an internal N-gon corner
still requires an actual face cut rather than averaging independent colours.
