sanitizer staging run lacked a test-only gate library after every production and
helper compile/link succeeded; a separate stage copied the unchanged plain-C
interposer and verified the real sanitizer fixture. That interposer is explicitly
uninstrumented; the application/core remain owned ASan/UBSan. Initial320 loader

its mandatory output argument (exit2); the same binary subsequently passes with
its real argument. None of these failures is relabeled as a successful run.

admission of other private lanes. Root Scene30 recipes and the unqualified
