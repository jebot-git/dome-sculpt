# Explicit native normal conversion and persistent ownership

The private candidate adds **Convert normal detail** to the universal Mesh menu
and the existing XR Source / cage panel. It converts eligible native historical
canonical normal detail into an explicit prepared frame/image representation.
The original complete paint, normal bitmap, material factors and deformation
remain owned and recoverable. Other baked channels, coverage and visible/hidden
editable layers remain intact; this operation does not flatten paint.

The conversion uses the previously qualified filtered-field kernel. It runs on
the existing background scene worker, with source/generation checks, one Undo,
exact Redo, cancellation and ordered Save. A physical trigger held across
controller activation cannot start an accidental paint stroke. Conversion is
available even when an old project no longer has a live Bake source or recipe.

Scene31 is emitted only when an actual opaque conversion lease is reachable.
Material wire13 wraps a real historical base layout and explicit physical/Mirror
capabilities; normal entry7 retains the actual prior entry shape and a pooled
root conversion anchor. Decode reruns conversion from retained input and checks
the serialized receipt, frames and image data before restoring shared authority.
Relabeled old versions, changed historical pixels, forged receipts and foreign
anchors refuse. Unconverted historical-normal guards remain intact.

Native New/Replace keys, an actual symmetric BaseRelative Mirror, and repeated
UV edits retain the conversion owner through native restart and exact history.
The original asymmetric Mirror refusal remains a negative control. The unused
automatic tangent-export prototype was removed; the published exporter is
unchanged and consumes the existing explicit prepared frames.
