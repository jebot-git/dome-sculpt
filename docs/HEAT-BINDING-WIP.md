# Native open-surface bone heat — private prototype

Base6a184f1, itself an unadmitted volume-weight experiment. The ordinary application, Surface Automatic and all public API/layout/schema behavior are unchanged. src/heat-binding.* is not yet in CMake. This is a distinct surface PDE, not volume-aware weighting and not a byte-equivalent Blender port. Its references are the pinned Blender3a4070ad meshlaplacian.cc cotangent/area heat, geometric normal and vertex-to-bone visibility paths already recorded in AUTOMATIC-VOLUME-WIP.

The initial native implementation assembles a symmetric cotangent finite-element matrix plus mass-lumped visible-source heat. Each deform-bone RHS is solved independently with bounded Jacobi-preconditioned CG and a recomputed true residual before acceptance. Output retains every raw vertex and triangle identity; no coordinate-only seam welding is performed. Work/memory are bounded before construction and during source queries/matrix iterations. Negative fields beyond the explicit numerical bound are refused, rather than silently clamped into a claimed positive PDE solution. Top-K/normalization happens after each complete field. There is no native authoring/history/Save/locks/affine adoption claim.
