# Historical MakeHuman reference

The previous explicit MakeHuman fallback used CC0 hm08 body, targets, rig and skin weights from the pinned revision in SOURCES.json. The converted mesh/targets/skeleton arrays and their generator have been removed. These records retain historical source hashes, grants and credits for existing user-authored projects; they contain no default model geometry. No MakeHuman program runtime is linked. Original native groom algorithms remain shared with the VRoid creator where useful.

Existing native projects retain their own saved geometry, paint, rig, morphs and legacy recipe metadata. They are not replaced or migrated automatically. New humanoids use only the verified CC0 VRoid female/male models.
