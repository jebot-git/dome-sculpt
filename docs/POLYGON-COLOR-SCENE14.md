# Durable editable polygon corner colors

This private checkpoint extends the existing native FLTK/OpenXR polygon workflow. Raw source `COLOR_0` can be converted with the actual visible skin/morph pose into editable native polygons while retaining the complete original source. Geometry edits, local and document history, cancellation, ordered Save, restart and explicit source Restore carry the current corner field together. It is not the completion of the full production objective.

## Current authority and persistence

`PolygonAuthority::colors` owns an immutable `PolygonColorField`: initial linear straight-alpha CORNER RGBA samples and bounded convex current-corner provenance. Source basis owners are shared through edits, rather than reconstructed from a material holder or averaged by position. Source expansion uses the exact captured native-vertex map; shared topological vertices whose evaluated poses disagree are refused with their original source untouched. Existing source triangle-basis and nonconstant dissolve refusals remain.

Scene14 uses polygon archive3. It reads the actual Scene13 placement/capsule representation as well as legacy archive1/2, deduplicates immutable `color_bases` and current `color_fields`, preserves shared owners on reload, and checks all refs, reachability, sorted stable IDs, unit RGBA and convex finite partitions before payload construction. Color and geometry/provenance entries share the existing bounded aggregate quota; unbound/orphan fields are rejected. Required Scene14 propagates through active, inactive and retained authorities. Older outer Scene versions cannot silently ignore this authority.

Scene surface DTOs alias their exact strong topology owner. Color validation uses ordered REST geometry before evaluated or world-space packing; independent retained normal-frame expansion follows its explicit REST map. Alpha-aware native workers and immutable Document picking use the same packed stream as rendering, including held-object preview deltas. Data is never relabelled as a replacement raw source or a fabricated preparation receipt.

The existing Polygon editor/menu/controller pages are reused. The editor's solid geometry preview remains the established diagnostic shading; the accepted surface uses the actual material and corner stream. All expensive capture, geometry, field and archive preparation runs on existing workers. Local history carries color and geometry atomically and accounts for corner provenance in its resource budget. Accepted Apply plus immediate Save captures the completed immutable endpoint. Empty geometry retains a complete latest-source capsule and renders no stale Volume or paint surface.

## Explicit current limits

Prepared color projections and normal-preparation topology changes require real adapters; retained source data alone is not permission to reinterpret those payloads. Current-field baking and appearance-transferring plane cuts are explicitly refused and disabled in their corresponding readiness/pickers. Color-aware polygon edge cuts remain supported. Retopology and voxel conversion retain their complete source object but produce their existing blank/clay outputs; further appearance transfer remains required. No general affine application support is claimed from the Scene13 codec dependency; its existing guards remain.

Generic PBR Automatic-alpha export now preserves referenced vertex transparency alongside material/texture alpha. The independent consumer fixture includes Automatic, Opaque, Mask and Blend for both gradients and seams. No shader readback or roundtrip is introduced.
