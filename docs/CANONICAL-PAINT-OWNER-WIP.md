# Canonical writable-paint owner: private foundation

The detached canonical paint UV factory now retains a complete immutable before
control, current writable geometry attachment and independent canonical normal
UV owner. It remaps current skin and morph arrays with the exact current vertex
map. Existing float/RGBA/PBR/baked/normal planes are retained rather than rasterized.
Paint metadata is snapshotted; const material/deformation/history roots keep
their actual identities. Fresh calls validate the full before material again.

This is a private factory foundation. It has no public Material pointer or
Scene37 publication, codec, Restore or document action. A detached owner cannot
make the existing paint-domain admission guard accept a Scene.

The model preflight counts actual inline decoder slots, including canonical
origin models and exact pose matrices. Real repeated references to one polygon
origin are pooled once; equal models in different inline slots are counted
separately. Bake recipes own settings/IDs, not another hidden model. The planner
replaces the current slot and charges the actual additional before capture.
It does not yet constitute prospective total paint/frame/domain/volume closure.

Matched optimized and sanitizer component consumers pass 1,259 checks/profile,
267 persistent ordinary-new prefixes and 588 callback cancellation points.

accepts the exact 8,000,000 model-entry boundary. One true ordered seam duplicate
predicts 8,000,128 and refuses before target copies. Removing only that preflight
call makes the same test fail. An independent same-address material mutation
also fails with the prior owner code and is rejected by the current code.
All figures are component scopes over unchanged matching foundation libraries;
no fresh whole-app or full-regression qualification is implied.

The full before-origin introduces material → origin → earlier-material edges.
Connected persistence needs a bounded owning lazy resolver with cycle/depth and
resource checks before completed hits, complete reachability, and earlier-binding
order. It must not drop source history or embed whole Scene snapshots.

public pointer order will be native_paint_frames (36), then
