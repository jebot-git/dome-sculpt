# Filtered Bake fidelity and explicit target resolution — implementation draft

Original64 retained-source graphical target data fails `.035` at 18/136 original
role probes; no original probe or bound is changed. This source draft is not yet
qualified or admitted. See ADVANCED-NORMAL-MATERIAL-TRANSFER-20261118.md.

New ObjectBakeSettings requests default normal_filter_quality1. The saved policy
is explicit and bounded: version1 checks rest-space normal conditioning,
quantization, and sampled filtered transfer against the same normal_error angle.
It tests nine quarter/midpoints in each fully projected interior bilinear cell,
using the actual target role basis, sampled RGBA8 vectors and authenticated source
projection/normal resolver. Prepared original/retained sources keep their sealed
paired resolver. Ordinary mesh and sculpt sources use a separate numeric sampler
extracted from the actual generic Bake normal path: interpolated source normals,
original texture UV/basis, explicit imported tangents and legacy raw coverage
follow the same validated function as rasterization. This numeric sampler cannot
mint prepared-frame authority. Missing ordinary-source frame bindings never skip
the check. Explicit raw, unprepared Bakes record policy0 and make no filtered
quality claim. Aggregate ray/raster budgets and cancellation bound
all work. No empty interior certificate authorizes a field. This is a sampled
rest-space contract, not an all-point or all-pose theorem. The independent native
and GL corpora retain their original component `.035`, RGB3 and gap7 checks.

Missing saved policy decodes as0 and reencodes without the new field. This keeps
real historical projects, normal recipes and replay semantics intact. Unknown
policy versions refuse. The regression fixture is the actual 487253-byte SAN
native-v2 mt1-rest-shared-retained.dsculpt; it is not regenerated by the new code.
The genuine source fixture's first Bake explicitly keeps its historical policy0,
so source64 images and source recipes remain the original qualification input.

On a new-policy quality refusal, the detached scene is never installed. Tests
retain the exact Scene, source/material owners, Undo/Redo, prior file bytes and
failed immediately ordered Save. The error identifies the selected map size
and tells the user to choose a larger target paint resolution and Bake again.
Original64 refusals remain separately named regressions.

The existing TextureResolution control/worker and FLTK texture-set dialog gain a
narrow unpainted-target route. It refuses original images, normal/prepared data,
rigs, membership, authored paint and retained domains. It reuses the existing private texture-set raster-resize foundation with a
narrow unpartitioned/unpainted route. It preserves exact geometry and immutable
material binding owners, layers/IDs and source Scene. SourceUV image resolution
is a separate operation; it does not resize the ordinary editable paint grid. Users
explicitly choose the higher target resolution; there is no automatic resize.
FLTK exposes a resolution-only dialog for an eligible typed target. The existing
XR panel stages the same control, with ordinary Cancel/accept semantics. Every
accepted resize and later Bake has its own native history step and ordered Save.
Authored/prepared field resizing still needs its separate owning adapter.
