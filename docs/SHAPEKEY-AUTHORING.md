# Shapekey authoring work in progress

The full production objective remains active. This private source builds on main
63df2c6, detached frame/key helpers ca67572 and the qualified Scene13 codec ad9.
It is not yet a complete native/controller editing workflow or a published
milestone. Desktop/controller controls, interactive sculpting, independent export
pixels, persistent-denial and whole-source sanitizer qualification remain work.

The native author_shapekey worker kernel creates neutral targets, captures a
pre-skin weighted mix, duplicates/mirrors, renames, replaces geometry and restores
the complete pre-authoring source. Target names and explicit stable frame IDs
remain separate from original imported/expression identities. Neutral, duplicate
and mix direction channels preserve actual artist data; geometric replacements
transport the previous artist endpoint by the geometry-frame change, retaining
REST attributes and other keys. N-only keys remain genuinely N-only. A new native
key does not claim an original source target index. Existing edited keys keep
source/expression identity and explicit origin-domain POSITION authority.

Scene16 retains the complete before-state as a direct immutable native object
source capsule. The existing PolygonOrigin data holder is reused for its actual
volume/paint/material/deformation/appearance/placement/source contents; no polygon
topology or PolygonAuthority is invented. Later polygon conversions carry the
shape source too. Archive v4 adds direct roots and origin-to-shape-source edges,
with cycle/depth/reachability checks and existing aggregate geometry/paint/image/
frame/deformation budgets. Legacy archive v1/v2 are unchanged. Private color v3
and Scene14/15 are coordinated dependencies still to be combined; this isolated
branch explicitly refuses those unimplemented versions until that union.

The first fresh coherent Release gate passes five suites: shapekey authoring
23 assertions (including actual CC0 VRoid artist-key modification and exact
save/reopen/Restore), original polygon-source archive, Scene13 placement and
persistent placement failures, and historical Scene schema compatibility. Logs
are artifacts/tests-shapekey-core-first.log/.xml in the primary repository.
No whole-current-source sanitizer, new GUI, HMD or independent graphical export
proof is claimed by that gate. Preserve the separate helper/component receipts.

Legacy baked normals without retained frame authority require the proper normal
preparation route. Polygon-authored paint converts only through the real same-
mesh Strict validator while retaining its original direct polygon source;
overlapping UVs receive unwrap guidance. These are staging constraints, not
completion of general normal preparation, polygon color transport or the full
production matrix.
