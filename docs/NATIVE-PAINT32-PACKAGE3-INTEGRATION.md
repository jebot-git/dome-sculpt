It does not consume normal34 public headers or archives. The sanitizer allocation
sweep's system-codec leak is a blocker, recorded in NATIVE-PAINT32-PACKAGE3.json;
do not admit this as complete HDR/OOM support.

  still-guarded source-only strict conversion.

Preserve the root normal34 changes while applying these seams. In particular,
keep the genuine-normal-frame guard around `domeSculptNormalTransport` extras;
a native paint coordinate layout has no imported normal frame. Preserve
canonical attribute/UV export, normal-field coverage/filter semantics and all
Scene35/material17 capability/pool/budget/retained-root checks. Package3 calls

canonical attributes/UV and native paint may need a new paired normal adapter;
do not silently admit those combinations or replace their role frame with
current authored UV0. Coexistence of different actors and capability contexts
also needs the root's real semantic tests.

There is no new public layout append in this follow-on. Private
EmissionExportImage/Prepared layouts changed, so rebuild every export/VRM/core
consumer. Reuse no old archive with a changed header. Keep the current root
page registry/extra pages: the component XR test inherited a count31 oracle,
which must not overwrite the newer source-visible/native-visible page contract.

Current successful evidence is scoped to native source4/current6, real64-pixel
paint, alpha cases, mixed actors, exact native/EXR recovery, explicit generic
export, controller/file work and compact/native desktop. It is not a qualified
new-format hardware, full ALL, Wayland, typed-MToon or general physical-domain
