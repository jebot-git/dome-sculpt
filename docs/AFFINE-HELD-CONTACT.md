# Held affine contact painting

Private source c638fee extends the ordered contact worker to simultaneous physical
holding and painting. Captured geometry remains in original scene-world space.
The controller callback inverses only the tracked similarity preview delta,
including its radius scale; it never approximates the underlying reflected/sheared
source matrix. The worker evaluates the current source pose and paints original
REST triangle/UV identities. Ordinary posed similarity objects use this evaluated
route too; the old synchronous rest paint cannot consume an unarmed posed trigger.

A physical grip release during contact queues acceptance instead of publishing
placement ahead of the painting worker. Under the existing source/pose lease,
the worker combines the latest preview E with paint into one immutable Scene,
one history endpoint and the exact completion captured by an immediately queued
Save. Native-local rebasing refuses while this source is captured. Focus loss
cancels unaccepted motion and paint. Failure preserves original authority,
restores the earlier preview and releases failed physical holding without an
allocating diagnostic path. Original exception_ptr reaches accepted Save; a
bounded native-worker notice retries status after memory returns.
