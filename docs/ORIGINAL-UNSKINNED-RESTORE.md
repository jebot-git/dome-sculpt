# Complete original-source Restore before a rig existed

A complete first rig-source capsule may legitimately record no original
skeleton. Restore now accepts that state on an explicitly editable current
rigged target with linked fitting off. It restores the complete original
paint/material/morph/shape/sculpt/deformation state, including no deformation,
and retains the existing name/identity/current placement policy. Missing rigs
do not imply linked membership; linked mode still refuses this new case. Legacy
original-rig/source-graph linked restoration is unchanged.

No origin is fabricated or inferred from missing metadata. Actual capture uses
the existing complete capture_polygon_origin factory; its original paint and
volume must exist, mesh must be active, and the detached result passes normal
Scene validation before cancellation/atomic adoption. The branch does not add
expensive duplicate legacy validation. Native desktop/controller wording now
says complete original-source restoration, matching what the shared Restore
operation already does. No persistent format or public layout changes.

Final Release and matching asserted O1ASan/UBSan/leaks overlays each pass37 real
checks, including actual existing native fitting Apply/controller page27,
queued Save/reopen, held/read-only authority and exact Undo/Redo. Bare and
morph-only originals retain real paint/material, a genuinely hidden authoring
layer/mask and original shape capsule. All134 actual persistent ordinary
new/new[] failure prefixes (65bare/69morph) pass in each profile, with exact
current Scene and successful full-source retry. The unchanged legacy23-check
fitting/real19-part CC0 VRoid/linked Restore fixture passes in both profiles.
The identical final fixture linked against the unchanged old runtime fails at
the exact original no-rig source guard; its negative is retained.

Scope is explicit: own three changed runtime TUs and fixtures with exact264
headers plus unchanged read-only coherent264 core/support, all instrumented in
the sanitizer profile. Link maps prove the old three members are not used.
The desktop label TU separately compiles with matching coherent-app flags.
This is not a fresh latest-main/all-project build, actual GUI/loader, GPU or
headset proof. CMake registers the two native targets; no redundant large full
suite is rerun. See validation/ORIGINAL-UNSKINNED-RESTORE.json.

This portable adapter does not admit the experimental general weight method or
the source-assisted appended API. Future late-allocation Save/export probes
must first consume the separate5ab IO ordering fix. No late-IO, general robust
weights, system installation or active-session claim is made here.
