# Native normal-frame capture — private continuation

This child of cab4669 adds actual native key-frame capture from a validated,
owned normal-map coordinate set when no retained frame exists. It is not admitted
to main and is not a general native derivative-to-standard-frame quality claim.
No public layout or archive version changes.

The original no-frame paint/material/deformation remains in shape_source.
Capture uses the current exact mesh/map association and each retained material
role's coordinate ID. Explicit generated_uv records the genuine selected set;
no imported artist tangent/source identity is fabricated. Native normal-map
frames store actual per-corner face-UV derivatives under FixedAttributes, not a
CanonicalMikk declaration. Existing normal/tangent target deltas and immutable
handedness constraints remain enforced. Untransformed native PBR UV2 is the new
tested route. Transformed normal coordinates and an ambiguous current/first-origin
association still refuse before scene publication; they need real adapters.

A valid non-affine UV2 quad exposed a genuine defect in an initial Mikk-based
capture: adjacent-face averaging changed a neutral key's pixels by3 against the
existing bound2. Source, binary and log are preserved. Capturing each actual
face derivative fixes that case to0; a genuinely nonplanar height0.65 surface
has maximum error1. Neither images nor bounds were changed. The earlier affine
coordinate capture (plane0/nonplanar2) is retained separately.

Current development proof is explicitly an overlay: the changed production TU
and complete graphical test TU are compiled against byte-identical public
headers and unchanged frozen cab4669 core/support/render archives. Link maps
prove the older author TU is not extracted. Both Release and O1 ASan/UBSan/leak
variants pass395 assertions, including actual native worker ordered Save/reopen,
one Undo/Redo, no-frame source Restore and independent emitted normal-map GLBs.
The existing shapekey authoring/strokes/prepared-key test objects additionally
pass3 Release and3 sanitizer overlays with the new production TU. All linked
C/C++ sanitizer core/support/render archives are instrumented; this is not a
fresh all-source native-capture build or whole regression claim.

Still required before broad integration: a fresh coherent final source build,
actual A770 on this native-capture source, malformed/ambiguous association and
cancel/allocation tests, broader preexisting morph/skin/world placement and
native typed-material capture, transformed-coordinate transport, and measured
quality/representation for arbitrary curved derivative fields. Keep the complete
original-frame/source/UV requirements active. No field or recipe from retained
paint or colour supplies normal authority.
