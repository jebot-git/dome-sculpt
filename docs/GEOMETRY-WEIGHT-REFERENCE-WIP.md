# Private native/unskinned reference-weight producer

This private descendant uses a genuine captured reference rig owner for native
unskinned target geometry in separate affine frames. Each actual REST mesh is
staged in its own world metric; current reference pose and target morph/pose/
paint data remain untouched. It does not fabricate a target skin or imported
appearance merely to satisfy an imported-source intent factory. Existing target
rigs require exact canonical full rest/bind/deform replay from the explicit
reference, not name-only or nearest-bone matching. All float components and
optional presence are compared exactly. Source/geometry changes and cancellation
refuse before adoption. The source-assisted/legacy public paths remain separate.

The private producer now stages actual skin and, where absent, exact reference
bind-space transport, honors influence/lock settings and captures the complete
first target source through the existing factory. Same-field retry is a no-op.
The narrow portable originally-unskinned Restore adapter is exact a5ab8c3 runtime.
No public API/menu, persistent format or class layout has been added here.

foreign-rig controls pass. The owning producer passes283 checks: actual generic

Two failures are preserved honestly. A serialized per-object assertion crossed

This is still experimental. Native fitted rigs own explicit bone-Y/length tails;
the current fixture/control uses coincident child-head endpoints and must not be
silently generalized to arbitrary forks or imported raw axes. Native handle
policy, connected/thin/near-contact/refinement/full pose stress, complete own
reference/producer sanitizer/fault gates and an actual new UI/controller method
remain. Nearest-vertex component support is not a complete facet Voronoi solver.
No full/latest-main, rendered-pixel, GPU/HMD or robust automatic-weight completion
claim is made. Before late-allocation Save/export probes, a new coherent child
must carry portable5ab IO ordering; frozen264 caller/publication evidence stays
separate and immutable.
