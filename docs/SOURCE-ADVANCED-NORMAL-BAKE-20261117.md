# Reprojected and retained normal Bake sources

This component extends ordinary prepared source reuse to genuine SourceUV
Rasterize and RetainSource recipes. The owning recipe is replayed, current
ordered corners and retained detail event are authenticated, and each normal
role uses its own original sampling coordinates. Material sampling retains its
separate current authority. Artist/morph/skin frame transport is unchanged.

The private resolver now owns its source projection and captured material
packet. A raw retained-detail event requires both the exact domain/detail
identity and its matching resolver; a bare callback cannot grant authority.
All three core translation units including the private header were rebuilt,
including the unchanged bake-authoring caller. No schema or frontend changes.

The new native fixture covers both normal roles, MToon versions, morph and
weighted nonuniform skinning, UV seam expansion, real repeated Bake, material
sampling, native persistence and ordered worker Save/Undo/Redo. It includes
independent double precision decoding and wrong-domain/omitted/swapped controls,
plus missing-recipe, modified-domain, stale-event and foreign-owner refusals.
The older suite's genuine advanced-recipe cases now require success; missing
source-data refusals are retained. The original frozen suites/results remain
separate immutable evidence.

At this source checkpoint, all six complete affected/tested translation units
and all three fresh component links pass. Runtime qualification is pending.
Two test declaration compile errors and a preparation-only dependency-roster
lookup failure are preserved in the new artifact namespace. No prior failure
or threshold was relabelled. Canonical/native32 and independent writable-paint
normal/material domains remain unsupported and required future adapters.
