# Canonical normal Bake source adapter — source checkpoint

This is an **uncompiled, unqualified production/test draft**, isolated from frozen
090f, advanced90fad/aa8 and current application/public/graphics consumers. The
previous advanced Release and strict sanitizer proof tuples remain separate.
No new product, GL context, installation or session operation has run here.

The adapter consumes the actual opaque `CanonicalNormalConversion`, active
`BakedNormalField`, `CanonicalNormalUv` and current frame/key/deformation owners.
Canonical materials currently have no typed MToon descriptor. Both stored field
planes are preserved using the renderer's prepared PBR column basis; the second
plane is not relabeled as a newly invented typed material. Normal coordinates
come from the genuine retained correspondence, while material/paint/emission
continue to use their actual current domains. Morph identities and weighted
normal inverse-transpose/tangent transport use the existing frame providers.

ClearBake releases the active field. Capture then evaluates the actual remaining
intrinsic map under the renderer's raw vertex-bitangent/PBR-column policy. It
never substitutes the conversion's historical baked pixels. A factory-only
transient overlay packet binds the exact current material/frame and deformation
owners, including Clear captures whose field event is absent. The normal
resolver verifies this binding, material source owner, actual baked event and
padding owner. Naked Bake, marker stripping, stale replacement events and
foreign Clear frame owners must refuse. The resolver itself requires pairing
even if a caller strips the packet certificate or removes its entire material
view; admission never depends only on the presence of an untrusted DTO marker. No persistent schema, frontend or
public TextureMaps layout changes are introduced.

Capture checks genuine field/origin/correspondence identity before any deep
validation and charges its bounded frame/field/domain arrays before allocation.
Its DAG walk uses immutable constant-time canonical cap metadata and walks actual
canonical before-material anchors before any deep checks. Existing
active/done ancestor traversal, cycle/depth limits, cancellation and historical
recipe-cap preflight remain. Higher historical declared caps are conservatively
refused by a smaller caller; this is not unbounded replay support. Current mesh,
source/UV pairing and opaque owner validity are checked before sampling.

The new native fixture constructs genuine first legacy Bake → opaque conversion
→ actual artist dual-role replacement → source reuse. Its 32 planned cases cover
MT0/MT1 artist input, unchanged/edited UV, existing/new-and-replaced key, rest/
weighted anisotropic pose, and live-field/Clear states. It independently decodes
both field planes and intrinsic fallback in double, rejects nonfinite samples,
and preserves the existing 3e-6 direct/.035 second-Bake bounds with same-interior
omission/swapped-role/wrong-domain controls where those domains are distinct.
Current material/paint sampling, sparse physical FLOAT emission (>1 witness),
Save/reopen, immediately ordered Save and exact Undo/Redo are also checked.
Negatives cover quota, capture cancellation, missing/foreign correspondence and
conversion, stale later field replacement, stripped markers, naked callbacks,
and a failed native worker preserving prior Save bytes and history. These are
source-level test intentions until actual compilation/runtime succeeds.

Independent writable-paint domains, native32 paint, combined Source8 normal
fields, and historical legacy canonical-preparation descendants remain explicitly
guarded and required subsequent work. This checkpoint does not claim those
families or desktop/XR/graphical correctness.
