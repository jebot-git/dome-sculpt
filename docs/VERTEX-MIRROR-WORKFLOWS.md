# Native vertex-position Mirror workflows

The ordinary Mirror action can again operate on native meshes whose reflected
vertices match but whose triangle diagonals differ. The full Dome Sculpt
production objective remains active; this is a private milestone, not main
admission, installation or full production qualification.

## Behavior

The native dialog and controller action explicitly choose **Vertex positions**.
The existing **Exact authored reflection** and **Relative artist-frame conversion**
remain separate choices. The C++ API default stays ExactAuthored; existing numeric
values0/1 and their strict replay/serialization are unchanged. VertexPositions
appends value2 without changing the request structure layout or archive formats.

The bounded worker reflects each complete native POSITION displacement about the
entered local X plane. Coincident source candidates must agree exactly; conflicting
seams refuse instead of choosing or averaging values. A field that still maps to
the retained original frame basis uses the established native frame writer.
Destination artist offsets follow its geometric change. Genuine independent
fields use the existing owning derivation and replay. This does not label generated
geometry as an exact reflection of authored normals or triangle patches.

Native first-source Restore and independent named-operation Restore checkpoints
keep their existing distinct semantics. Classification/hash/corner scans accept
the actual cancellation callback. Existing guarded publication, exact Undo/Redo,
paint preservation and ordered Save remain in force.
