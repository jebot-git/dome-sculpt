# VRM1 differing and zero UV expression targets

Private runtime `7e5f869`, following `ccc109e`, adds genuine typed painted export
for differing or zero UV targets when the actual upper material contributions
are provably UV-invariant. Original source material bindings remain on the lower
materials. Only the independent paint primitive omits those UV bindings, keeping
its true writable coordinates fixed; no original target, sampler, image,
geometry, skin, morph or metadata is flattened to manufacture that result.

The private compiler checks all original preset/custom definitions. A shared
shade role already contains independent paint. Other shade/emission components
must have zero effective initial and future coefficients, absent source images,
or constant active RGB components across their actual immutable source images.
Real image scans enforce prospective pixel/work limits and cancellation. Emission
strength and native inspector corrections retain their actual meaning. A private
compiler flag records the result; no trusted caller flag or serialized authority
is introduced. Normal/derived/native/physical and other unsupported role guards
remain in place, including genuine root35 guards at later semantic integration.

Source metadata bounds remain unchanged. Raw doubles are checked before F32
conversion, and existing common-target carrier precision checks remain. The
[VRM1 expression specification](https://github.com/vrm-c/vrm-specification/blob/94e82dd346fa6cf0337c4421728640e5252dd38e/specification/VRMC_vrm-1.0/expressions.md)
remains pinned at `94e82dd`; numeric-version admission is not substituted for
actual source/role ownership.
