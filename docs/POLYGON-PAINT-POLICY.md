# Explicit polygon UV paint policy

`PaintUvPolicy::PolygonAuthored` distinguishes an editable N-gon derivative from a strict unique atlas and from original source-authored texture coordinates. Polygon UVs may overlap or contain generated, temporarily unpaintable faces. Existing bounded multi-candidate rasterization limits still apply; this policy does not assert that overlapping UVs are unique.

The generic untextured factory still accepts only Strict. The existing SourceAuthored decoder still requires original source maps. Only the private polygon conversion helper prepares a PolygonAuthored surface while preserving the full paint snapshot: every layer identity, order, name, visibility, opacity, allocated tile byte, active/future ID, source map and bake reference. It replaces only immutable surface/raster metadata and invalidates its derived composite cache. Source geometry/paint remains untouched on failure or cancellation.

The existing two-argument `PaintedMesh::decode` ABI continues to reject the new policy. The additive three-argument overload can structurally parse `polygon-authored` only with an explicit true argument. This is not source authority: the Scene12 codec must subsequently require the exact active polygon REST/index/UV witness for every current or retained painted owner, and reject unbound or older-schema payloads. That Scene admission is a separate integration step, still pending in this checkpoint. SourceMaterial UV origins and prepared-color receipts have no implicit polygon witness.

Fresh CPU Release and complete own-core/support C/C++ ASan/UBSan with leak checks pass the new 14 direct policy checks, all 4 measured cancellation points and all 22 persistent owned-allocation failure boundaries, plus existing SourceMaps, SourceUV and Scene12 archive fixtures (four suite names across two invocations per configuration). SourceMaps/UV/policy took 2.57 seconds Release and 19.16 seconds SAN; the Scene12 archive replay also passed separately. The direct test proves exact tile/source preservation, old decoder/factory refusal, distinct policy admission, cancellation, injected failure and deterministic retry. It does not qualify a complete Scene12 paint witness or the native/XR polygon workflow.
