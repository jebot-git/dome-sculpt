PBR/MToon × quarter/2^-24 emission-coverage cases. Each has a real original UV1
source, a separately prepared current UV0 atlas
`(.125+.75u, .0625+.875v)`, Scene42/Paint8 authority, a genuine installed FLOAT
field, and actual retained hidden target/source/sibling editable data. Immutable
source coefficients retain the authored 50000+32*x and tiny-green range; editable
physical strokes respect the separate named native brush limit.

Each case publishes seven original/accepted/undone/redone native endpoints using
the original public desktop slider conversions and XR default settings. Complete
native expectations come from synchronous Bake followed by independent 4096-texel
UV1 affine/filter/typed-strength/normal/FLOAT arithmetic. The actual Document
worker and ordered Save must match that full endpoint, reopen exactly, preserve
hidden owners and support one exact Undo/Redo. The native numeric oracle uses a
fixed absolute floor 1e-14 and relative bound 2e-6; normal encoding remains within
one RGB8 unit. This stricter new tiny-field oracle does not edit old tests.

The additional `--inspect FILE` mode reopens through the actual Scene decoder.
It is the native endpoint inspector used by the public scripts, not an injected
application observer.

## Independent visible-source controls

Each case additionally authors a genuine *visible* Source8 scene matching the
varied-frame fixture: isolated nonplanar triangles, varied per-corner normals,
rotated/skewed original UV1 plus normal-role affine/scale, distinct inset current
UV0, spatial common normal coverage 191/65, independent quarter/tiny FLOAT
coverage and a nonempty hidden physical tile. The common normal coverage is not
borrowed from emission coverage.

The native material/reference and baked base use exact decoded sRGB136 gray.
Typed shade is `(gray*.25,gray*.3,gray*.35)` with toony 0. White typed saturation
cannot count as a normal proof. These fixtures still require numerical owning
qualification; the settings are copied from the strengthened source fixture.

For four declared interior probes, `--visible-control` independently derives
original-role and current per-corner tangent frames, filters premultiplied common
normal coefficients, resolves FLOAT/legacy/background radiance and casts a public
camera pixel ray. It serializes a plain ordinary-material native scene with the
resulting constant geometry normal/emission. It does not use product Source8
sampling, Mikk generation, renderer callbacks or SurfaceQuery as the oracle.

Desktop uses the actual public GL drawable dimensions, the existing 2.2 camera
and 45-degree vertical projection. XR uses the runtime's actual 320-square eye
images, ±.032 eye offsets/±.6 FOV and source-derived initial canvas anchor. The
real applications display those ordinary native controls; no standalone renderer
image substitutes for an application view. Projection assumptions are explicit
qualification predicates, not values learned from screenshots.

The new runtime mode observes latest released actual eye images and waits for
external image inspection before normal session exit. It issues no sculpt,
paint, menu or history actions in these view-only instances and does not read or
mutate product state. The original Apply mode remains intact. Every view must
retain native contents, current app/runtime process maps, balanced stereo
frame/image/session lifetime and the required actual hardware renderer.

Source versus independent control must differ by at most 3 RGB units at each
probe. A hidden-geometry counterfactual must differ by at least 12 units, so
shared blank/background pixels cannot pass. An additional ordinary control omits
only baked normal detail; each case and each XR eye must have a measured effect
of at least 3 RGB units across its four probes. Fully clipped-white equality is
explicitly rejected. These thresholds are fixed before execution; no threshold
learning, fallback or automatic retry is authorized.

Public-source comparisons and independent native comparisons must both pass.
The tiny FLOAT coefficient checks are native numerical evidence; an RGB8 display
comparison is not a calibrated tiny-radiance measurement. Physical HMD input,
90 Hz pacing, native-Wayland shell acceptance, deterministic public mid-helper
cancellation and the complete production objective remain separate requirements.
