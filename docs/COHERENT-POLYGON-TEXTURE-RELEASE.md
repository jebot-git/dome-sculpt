# Private coherent polygon and texture-set application — 2026-11-06

This candidate combines current main's remeshing/input/rendering foundation
with owning polygon paint/normal preservation, independent texture sets and
shared-geometry multi-material GLB export. It extends the existing native
FLTK/OpenXR application. It is not a main admission or production completion.

Eligible polygon edits retain their actual before/current paint and normal
owners through save, reopen, undo and source restoration. Supported plain mesh
texture sets have independently editable materials, paint and layers on one
shared geometry. Portable export emits nonempty material primitives sharing
vertex, skin and morph data; editable export also retains the native project.
Scene40 can contain separate polygon-field and texture-set actors without
discarding either owning graph. Unsupported per-set source/history adapters
remain explicit refusals.
