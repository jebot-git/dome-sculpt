## Diagnosis and implementation

Cold P1 does not execute the dirty-tile update loop. Initial tile, representative,
position, chunk and global-run directories were instead built as repeated
persistent AVL edits. Each insertion clones a search/rotation path. Intermediate
roots die, but their owning requests stay conservatively charged for the operation.
The result can exhaust a cumulative working envelope despite a much lower live
set. The new initial path constructs balanced trees bottom-up from strict sorted
keys: exactly one final node per key, with no discarded insertion paths.

The same first_request/first_position representative keys, bitwise vertex/normal
values, winding and original global cell/run order remain authoritative. Position
and run sorting ticks/cancels for every comparison. Strict ordering and duplicate
validation occur before accepting the complete root; old ownership survives a
failed/cancelled partial build. Existing AVL node/member and persistent update
bodies are unchanged. Public chunk-header bytes remain exact d1. No schema, query
namespace, Source/paint/normal adapter, scalar/geometry boundary or numerical
1GiB/512MiB limit is changed.

Initial bounded representative/run arrays reserve their complete envelopes before
allocation. They are declared after lexical scratch reservations, so their
element owners and capacities die before the reservations release on every path.
Per-chunk vertex deduplication map storage is similarly reserved before output
allocation and released only after that map dies. Geometry arrays stay permanently
charged even after the local map reservation ends.

Local dirty-tile extraction is serial. One complete maximum tile workspace is
reserved before extraction. A returned tile's actual retained payload is then
permanently charged while the temporary maximum is still held, before inserting
its immutable pointer into the next directory. The returned local extraction
object dies before the scratch lease; the directory-held tile remains covered by
its permanent charge. Empty extraction retains no tile payload. Old immutable
owners remain charged separately. This is a conservative overlap, not subtraction
based merely on iteration count.

The reported working envelope is now its high-water mark, preserving transient
peaks after proven lexical releases. The sequential legacy initial factory keeps
its existing full extraction-cap preflight; that bound contributes to the peak,
and its retained stats stay charged while the new directory is built. Remaining
incremental AVL path requests are still conservatively cumulative; no unproved
release or blanket correction of all allocation accounting is claimed. Guard
failure diagnostics include phase, prior charge, requested count/stride and limit.
