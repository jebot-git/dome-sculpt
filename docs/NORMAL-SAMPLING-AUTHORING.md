# Explicit retained normal-detail authoring

The native UV editor and shared controller UV panel now offer **Keep normal
detail**. Historical projects default to their existing raster transfer.
Selecting the option retains the original intrinsic sampling field through UV
Scale and rotation, and the accepted worker captures that choice with its exact
source lease. Changing the choice after Apply is rejected. A restarted retained
domain stays retained; it cannot silently revert to raster sampling.

The control explains its current output limit: save the native project;
glTF/VRM export still needs a sampling conversion. The retained-domain format
export guard remains active. This checkpoint does not claim a standard-format
normal compiler, new normal Bake-node transitions, independent split-corner key
authoring, or complete normal/colour UV interoperability.

Mode-only Apply is one real source-retaining conversion, even if no UV moved.
UV-local Undo/Redo preserve the draft choice. Cancel, controller focus loss and
native Ctrl+W discard it. A Save queued behind accepted UV work writes the sealed
accepted result; global Undo/Redo restore the exact complete before/after Scene.
The original frame and source authority, current paint, pose and weights remain
retained. Source admission also checks the strong polygon, material,
deformation, appearance and shape-source owners, using the check-only lease
strengthening independently supplied by the colour-UV agent.

The owning paired-surface envelope is exercised with protected, fractional and
full normal coverage. RGBA-only replacement preserves the independent normal
event and resolved pre-filter fields even when common colour coverage expands.
Clear switches explicitly to the intrinsic field. A byte-identical positive
normal Bake cannot impersonate the captured event; it refuses until a genuine
new owning-node transition exists. Complete restart, repeat UV transfer and
malformed event/before-state association are covered. Bare unbound paint leaves
still cannot authenticate this interpretation.
